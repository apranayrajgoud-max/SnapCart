# SnapCart 🛒

A fully responsive e-commerce product page with a working shopping cart, search/filter, checkout flow, and real user authentication — built with vanilla HTML, CSS, and JavaScript (no frameworks).

**Live site:** [snap-cart-beryl.vercel.app](https://snap-cart-beryl.vercel.app)



## Features

- 🛍️ **Product listing** — 10 products with images, names, prices, and categories
- 🛒 **Live shopping cart** — sidebar with quantities, running total, and remove/quantity controls
- 💾 **Persistent cart** — saved to `localStorage`, survives page refresh
- 🔍 **Search & filter** — filter products by name or category in real time
- 📱 **Fully responsive** — works on mobile and desktop
- 🧾 **Checkout flow** — order summary and confirmation screen (demo only, no real payment)
- 🔐 **User authentication** — sign up / log in / log out with Firebase Authentication; shop page is protected and only accessible when logged in

## Tech Stack

- **Frontend:** HTML5, CSS3 (custom properties, Grid, Flexbox), vanilla JavaScript (ES Modules)
- **Authentication:** Firebase Authentication (Email/Password)
- **Storage:** Browser `localStorage` for cart persistence
- **Hosting:** Vercel
